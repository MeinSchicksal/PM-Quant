数据源与状态指标说明

新手指南

一、顶部状态与 4 条实时行情源（绿 / 黄 / 红规则）

绿色 · 正常
4/4 正常 · 服务在线：BTC 现货（BN/KR/CB/OKX）、Poly 盘口、Poly 成交 3 条 WebSocket 与 Chainlink 预言机全部实时同步无滞后。
黄色 · 降级
链路降级（HTTP 降级 / 滞后 >10s）：某条 WS 断开或触发“防积压滞后护栏”正在重连，系统已自动由实时 HTTP REST 或稳态基差顶上，不中断监控。
红色 · 异常
断流 / 空盘口 / 接口变更暂停：现货超过 3s 无更新、盘口为空或上游接口格式漂移；死人开关已自动撤单并禁止开新仓保护资金。
灰色 · 离线
引擎离线 / 等待开盘：仅看板服务开着，后台交易管道未运行（live.json 超 10s 未更新）。运行 python main.py start 或 run 即可启动。

二、网络延迟与准度基准（判断真 Alpha 的核心指标）

平均 RTT
4 条行情链路的平均往返耗时（ms）。海外低延迟服务器通常在 10 ~ 80 ms；本机代理偏高属正常现象，策略会自动按实测 RTT 建模发单延迟。
信号-交易所差
公式：现货源延迟 − Polymarket 盘口延迟。绿色（≤ +30ms）表示链路延迟同步；黄色（> +100ms）说明现货链路往返偏慢。注意：生产环境强烈默认使用 binance（全球 BTC 定价中心），切到 Kraken 等二线小所虽 ping 低但价格发现往往慢 1~5 秒，反而极易引发 Maker 逆向选择。
Brier (模型 / 盘口)
固定中段（tau ≤ 150s）预测均方误差，越小越准（0=神准，0.25=瞎猜 50/50）。绿色代表模型预测打赢盘口市价（存在独立概率 Alpha）；黄色代表模型暂时弱于盘口（小样本有噪声，建议观察 ≥300 窗）。

微观风控与行情形态说明

状态字典

一、微观形态标签（共 8 种，用于事后归因，不直接拦截开仓）

窄幅震荡
range_bound：偏离开盘价较小且方向信噪比低，价格在基准附近来回拉锯。
常态波动
normal_oscillation：常规 5 分钟震荡市况，买卖盘口深度正常，策略主战场。
温和偏态漂移
skewed_drift：价格已偏向某一侧（胜率偏离 50%），但尚未形成极端单边突破。
单边强势多/空
trending_up / trending_down：现货显著脱离基准线且信噪比 > 1.8，趋势方向明确。
宽价差低流动性
wide_spread：盘口买卖价差超过 $0.06，做市商变谨慎，吃单摩擦成本升高。
毒流冲击
toxic：现货 2~3 秒内突发急剧跳变，系统自动撤回在途被动挂单防被点杀。
尾盘冻结
tail_freeze：距离结算不足 15 秒，停止新开仓与补腿，持仓等待到期交割。
