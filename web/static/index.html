一、顶部连接与右侧状态徽章含义

服务在线
浏览器 ↔ 本地看板正常：页面与本地 8900 Web 服务通信正常；若显示 连接中断，说明看板服务已停止。
4 源正常
全部数据流实时健康：交易管道运行中，且 Polymarket 盘口、WebSocket 成交、BTC 现货、Chainlink TWAP 均新鲜无阻断，系统可正常交易。
TWAP 滞后
Chainlink 60s TWAP 暂未更新（>10s）：属外部预言机接口短时延迟，系统会自动切换至「实时现货 + 稳态基差」估算真实价格，无需人工干预。
现货断流
BTC 现货连续失败（>3s）：Binance/OKX 均无法获取最新价格。死人开关已自动撤回所有在途挂单并禁止新开仓，请检查本机网络或代理节点。
风控告警
触发账户保护：达到单日最大回撤（$15）或连亏 3 轮冷却，系统已自动锁仓/暂停开新仓，防止连续逆风扩大亏损。
管道待机/离线
后台交易管道未运行：仅看板服务开着，live.json 超过 10 秒未更新（不会下单或录行情）。执行 python main.py start 或 run 即可启动。

二、实时延迟与网络遥测指标

Polymarket 盘口
拉取 Up / Down 订单簿的往返耗时（ms）。正常范围 150 ~ 500 ms；若持续超过 1500 ms 可能导致 300ms 延迟 IOC 吃单错失率上升。
Chainlink 预言机
拉取 BTC 现货与 Chainlink 官方结算参考价的延迟（ms）。注意本市场正式结算依据为 Chainlink 60 秒时间加权均价（TWAP）。
吞吐 / RTT / 累计
依次代表每秒下行行情速率（KB/s）、平均网络往返延迟（ms）、本次启动累计接收流量（MB）。管道运行中吞吐通常在 3 ~ 15 KB/s 波动。

微观风控与行情形态说明

状态字典

一、微观形态标签（共 8 种，用于事后归因，不直接拦截开仓）

窄幅震荡
range_bound：偏离开盘价较小且方向信噪比低，价格在基准附近来回拉锯。
常态波动
normal_oscillation：常规 5 分钟震荡市况，买卖盘口深度正常，策略主战场。
温和偏态漂移
skewed_drift：价格已偏向某一侧（胜率偏离 50%），但尚未形成极端单边突破。
单边强势多/空
trending_up / trending_down：现货显著脱离基准线且信噪比 > 1.8，趋势方向明确。
宽价差低流动性
wide_spread：盘口买卖价差超过 $0.06，做市商变谨慎，吃单摩擦成本升高。
毒流冲击
toxic：现货 2~3 秒内突发急剧跳变，系统自动撤回在途被动挂单防被点杀。
尾盘冻结
tail_freeze：距离结算不足 15 秒，停止新开仓与补腿，持仓等待到期交割。
