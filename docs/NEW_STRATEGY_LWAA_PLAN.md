## 二、 全新策略数学与逻辑详解

### 1. 为什么选择尾盘（$\tau \in [15s, 60s]$）？
二元期权价格在临近到期时会发生极端的**凸性坍塌（Convexity Collapse）**：
- 设当前现货价格为 $S_t$，本轮开盘基准价为 $K$，剩余时间为 $\tau$，已实现短期波动率为 $\sigma$。
- 此时到期结算胜率不是 0.50，而是由无套利积分决定：
  $$Z = \frac{\ln(S_t / K)}{\sigma \sqrt{\tau}}$$
  $$P(\text{Up}) = \Phi(Z)$$
- 当 $\tau \le 45s$ 且现货已偏离开盘价超过 $2.5\sigma\sqrt{\tau}$ 时，真实结算概率通常已经高达 **$\ge 92\%$ 或 $\le 8\%$**。

### 2. 核心盈利来源：捕捉 Polymarket 散户的“非理性彩票溢价”与“迟钝报价”
在真实的 Polymarket 盘口中，散户具有经典的**长尾偏好（Favorite-Longshot Bias）**：
- 哪怕胜率已经跌到 5%，散户依然愿意在 0.08 ~ 0.12 去挂单买入“博反转奇迹”；
- 哪怕胜率已经达到 95%，依然有散户在 0.88 ~ 0.91 挂单卖出以提前止盈锁仓。

**策略设计了两套互补的进攻模型**：

#### 模型 A：高胜率确定性吃单（The Closer）
- **触发条件**：
  1. $\tau \in [15s, 50s]$；
  2. 真实胜率计算值 $P^* \ge 0.92$（即胜负基本锁定）；
  3. 盘口卖一价（Ask）存在散户提前抛售的折价（例如 Ask $\le 0.88$）；
  4. 净期望值扣除手续费后：
     $$\text{Edge} = P^* - \text{Ask} - \text{Fee}(\text{Ask}) \ge 0.03 \text{ USD/股}$$
- **执行方式**：主动吃单买入该大概率边，**持有到期直接兑现 1.00 USD**。
- **收益特征**：单笔赚取 0.08 ~ 0.12 USD，胜率极高（$\ge 90\%$），直接消除了“第二腿无法对冲”的心头大患。

#### 模型 B：低价深度反向挂单吸收（The Tail Harvester）
- **触发条件**：
  1. $\tau \in [30s, 90s]$；
  2. 真实胜率 $P^* \le 0.05$（即该方向几乎不可能获胜）；
  3. 市场有非理性买盘在 $0.06 \sim 0.10$ 试图接飞刀；
- **执行方式**：在劣势方高位挂限价单卖出（或利用抵押拆分），向狂热散户出售高估的废纸，收取纯粹的时间价值衰减。

## 三、 风控体系与铁律边界

为了彻底根除过去“一笔亏损吞噬 8 笔盈利”的惨状，新方案设定四道硬核红线：

1. **红线一：严禁市价恐慌斩仓（No Panic Taker Unwind）**
   - 彻底废除 `taker_unwind` 机制。在二元期权里，于 0.10 割肉本质上是给对手送出极其廉价的波动率，绝不在流动性踩踏时主动自杀。
2. **红线二：参考源基差熔断（Basis Drift Breaker）**
   - 结算以 Chainlink 为唯一基准。若币安现货与 Chainlink 之间的瞬时价差（Basis）超过 $12 USD，直接判定为基准错位，全窗暂停交易。
3. **红线三：极小仓位起步与凯利上限（Fractional Sizing）**
   - 单窗固定 1 手（5 股），最高不超 2 手（10 股），绝对资金敞口严格控制在 3.0 ~ 5.0 USD 以内。
4. **红线四：严格的非交易区间（Silence Corridor）**
   - $\tau > 90s$ 且处于 $[0.40, 0.60]$ 震荡区间时，系统处于完全静默状态，不浪费弹药参与 50/50 的随机漫步。

## 四、 实现技术手段（精简交代）

新策略无需复杂的 Avellaneda-Stoikov 双边做市方程，技术实现大幅度简化：

1. **信号与概率引擎（Signal Engine）**：
   - 采用多步 EWMA 动态波动率 + Student-t 厚尾分布实时修正积分胜率 $\Phi(Z)$；
   - 接入币安 100ms 逐笔行情流计算瞬时脉冲与冲击弹性。
2. **状态机重构（Single-Leg Lifecycle）**：
   - 废除繁复的“第一腿买入 -> 寻找第二腿对冲”的双腿状态机；
   - 改造为标准事件驱动流：`Signal Trigger -> Pre-trade Guard -> Atomic Entry -> Expire Settle`。
3. **高精度微秒级计时器（Precise Tau Tracker）**：
   - 接入本地 NTP 高精时钟，确保 $\tau$ 倒计时的精度在 10ms 以内，精准锁定尾盘 15~60 秒的决胜窗口。
