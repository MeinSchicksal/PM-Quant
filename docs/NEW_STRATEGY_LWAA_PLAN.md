# PM-Quant v2.2 双阶段动态吸收策略方案（MWDE + LWAA）

核心宗旨：彻底告别前两分钟“被动双边挂单、被动等对冲、逆风跌停斩仓”的死循环，转向基于确定性概率优势的“主动单向吸收 + 持有到期 + 结构性防守”。

## 一、范式转变

早期 v1.x 被动做市在前 2 分钟进场（tau 180~300s，胜率接近 50/50 纯随机），强行追求 Up/Down 双边等量配对，盘口常驻被动 Maker 任由币安脉冲扫单穿透，逆风漂移时在地板价市价斩仓，每窗必进、过度交易。

v2.2 改为分两阶段选择性进场：单向确定性吸收，不强求配对；角色是条件触发型定向流动性提供者与瞬时错价吃单方；出场改为胜率加权持有到期，不割肉送流动性；高信度过滤，只打高确定性牌局。

## 二、概率引擎

到期结算胜率由无套利积分决定。设参考价 S_t、窗口开盘基准价 K、剩余时间 tau、已实现波动率 vol_bps（bps/5m）：

```
σ_τ = (vol_bps / 10000) · sqrt(tau / 300)
Z   = ln(S_t / K) / σ_τ
P(Up) = Φ(Z)
```

K 优先取 Polymarket 官方 Chainlink 60s TWAP 开盘价；S_t 优先取实时 Poly TWAP，缺失或过期时回退币安现货对开盘基准。vol_bps 由实时现货序列的 EWMA 滚动计算。tau 越小、偏离越大，胜率越向 0/1 坍塌；概率严格夹在 [0.01, 0.99]，到期前不取 0% 或 100%。Φ 为标准正态累积分布。

## 三、两阶段进场逻辑

### 阶段 1：MWDE 前半程顺势低吸（tau 120~240s，即开盘后 60~180s）

正常波动区间顺当前漂移选边：现货高于开盘基准或 P(Up) ≥ 0.50 选 Up，否则选 Down。只在折价进场——卖一价 ≤ $0.45 且扣费后净优势 ≥ $0.01 时吃单；否则买一价 ≤ $0.45 时挂 Maker 单（可在价差内 improve 一档，价格上限 $0.45）。

大涨大跌警惕：若上一轮绝对位移 ≥ $40，警惕单边延续，识别盘口高价（市场共识）一侧。高价侧卖一价落在 [0.45, 0.65] 时优先吃单；超过 $0.70 坚决不追高；买一价落在 [0.45, 0.65] 时挂单。

### 阶段 2：LWAA 尾盘高确信吸收（tau 15~120s，即开盘后 180~285s）

仅当某侧真实结算概率 P\* ≥ 0.80 才选为目标侧。吃单路径：卖一价落在入场走廊 [0.35, 0.65] 且不超过硬顶 $0.70，扣费后净优势 `P* − ask − fee ≥ 0.02` 时主动吃单。挂单路径：买一价动态挂单（join 或在价差内 improve，上限 $0.65），净优势 ≥ 0.02 时挂 Maker 单零费率排队。每窗最多挂单尝试 1 次，挂不上不再追挂，死扛等待到期。

两阶段在 tau=120s 无缝衔接，零时间断层。

## 四、持仓与出场

单腿成交后死扛到结算，不恐慌斩仓（`ALLOW_TAKER_UNWIND=False`）。只有当对家卖一价使 `pair_cost = 持仓均价 + 对家 ask + fee ≤ 1.00` 时，才吃单补腿，锁定到期必兑 $1.00 的无风险利润。尾盘冻结（tau < 15s）停止新开仓、撤回挂单，持仓持有到结算。Up/Down 等量完全配对后持有到结算，兑现保证 $1.00。

## 五、风控铁律

1. 严禁市价恐慌斩仓，绝不在流动性踩踏时主动自杀。
2. 单窗限开 1 仓（`MAX_ENTRIES_PER_WINDOW=1`），1~2 手（5~10 股），绝对资金敞口控制在数美元。
3. 追高硬顶 $0.70、入场走廊上限 $0.65，绝不追高；两腿总成本超过 $1.00 的补腿一律禁止。
4. 断流死人开关 3 秒撤单；单日累计回撤 $15 熔断、连亏 3 轮冷却；单窗硬亏损包络 $5。
5. 互补盘口无套利校正：决策与撮合前强制 `ask_up + ask_down ≥ 1.00`、`bid_up + bid_down ≤ 1.00`，杜绝把低于 $1 的配对当成无风险利润。

## 六、盈利来源假设（待验证）

策略假设 Polymarket 散户存在长尾偏好（Favorite-Longshot Bias）与迟钝报价：胜率已高时仍有人提前止盈抛售形成折价，胜率已低时仍有人博反转。v2.2 试图在尾盘高确信阶段吸收这些折价。但这是假设，不是已证明的 edge——必须在样本外回放与向前纸面中、在同一套费用/深度/排队假设下验证净期望显著为正，才允许放大仓位。
