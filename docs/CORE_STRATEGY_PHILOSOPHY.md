# PM-Quant 核心交易哲学与避坑准则

适用标的：Polymarket BTC 5 分钟 Up/Down 二元预测市场。核心原则：**如无必要，勿增实体；宁缺毋滥，赚多亏少**。

## 1. 核心哲学：极简、克制与正期望

在二元期权高频交易中，系统亏损往往不是因为“模型太简单”，恰恰是因为**盲目堆砌功能，导致规则互相打架、决策延迟暴增、过度拟合，最终演变为账面看上去很高级、实盘赚的小钱全被一两笔灾难性失误亏光**。本系统的最高准则是：

1. **单一决策内核**：全系统只有一个大脑，绝不引入多策略自相对冲或多智能体投票赛马。
2. **只信微观物理量**：只关注现货基准偏离（bps）、微观滚动波动率 σ、以及盘口挂单排队深度。坚决拒绝滞后的传统技术指标（RSI、MACD）与社交情绪噪声。
3. **非侵入式工具原则**：除核心决策外，任何辅助工具（死人开关、形态归因）只能作为纯底线安全兜底或纯事后统计记账，绝不允许增加额外的开仓门槛或交易阻力。

## 2. 历史病根与当前定位

早期被动双边做市路线（v1.x）在真实录制窗口的事件驱动回放中反复检验，结论一致：**没有任何统计证据支持正期望**，点估计为负、95% 置信区间跨零。修好撮合缺陷（无成交也默认消耗队列、Taker 无限深度）后策略依然不赚钱——问题在策略本身没有 edge，而不只是记账错误。

亏损的两个主要病根：其一，第 1 腿成交后用市价吃第 2 腿，两腿总成本经常超过到期胜者 $1.00 的兑现上限，机器人以为在“消除风险”，实际买入了到期必亏的确定性负资产；其二，单边裸头寸既不配对也不止损，方向押错即整笔归零。

v2.2 据此转向**单向定向吸收 + 持有到期**：不再强行双边配对，不再恐慌斩仓，只在能锁定 `pair_cost ≤ $1.00` 时才补腿。但范式转变本身不等于 edge。当前系统的正确定位是**一个可审计的研究/纸面交易框架，不是一个已被验证的正期望策略**。任何实盘或加仓决定，都必须等到新的回放/向前纸面在同一套费用、深度、排队假设下给出显著为正的期望。

## 3. 交易准则：三做与三不做

### 三做

1. **顺势低吸 + 尾盘高确信吸收**：前半程（tau 120~240s）顺漂移方向、只在折价 ≤ $0.45 进场；尾盘（tau 15~120s）只在真实结算概率 P\* ≥ 0.80 且扣费后净优势 ≥ $0.02 时吸收。大涨大跌后警惕单边延续，优先买入盘口高价（市场共识）一侧。
2. **单窗严格限开 1 仓**：一个 5 分钟窗口内开仓上限锁定为 1 次。无论首腿是止盈配平还是持有到期，本轮后续时间一律锁仓待机，杜绝在剩余尾盘里情绪化反扑。
3. **持有到期 + 只锁无风险配对**：单腿成交后死扛到结算；只有当对家卖一价能让两腿总成本 `pair_cost ≤ $1.00` 时，才吃单补腿，锁定到期必兑 $1.00 的无风险利润。

### 三不做

1. **绝不恐慌斩仓**：彻底废除市价割肉（`ALLOW_TAKER_UNWIND=False`）。在二元期权里于地板价割肉本质上是给对手送出极其廉价的波动率，绝不在流动性踩踏时主动自杀。
2. **绝不追高与天价买亏损**：买价超过硬顶 $0.70 坚决不追；两腿总成本超过 $1.00 的补腿一律禁止，绝不花高于 $1.00 的天价去买只有 $1.00 兑现的虚假安全。
3. **绝不多策略自相残杀、绝不断网裸奔**：禁止任何“一个看多一个看空”的投票/赛马逻辑，避免双向支付滑点与手续费；本地与交易所心跳中断超过 3 秒，死人开关自动撤回所有在途挂单，防止网络故障时挂单被动穿仓。

## 4. 落地实施规范

核心策略参数锁定：`MAX_ENTRIES_PER_WINDOW=1`（单窗限开 1 仓）、`DEADMAN_TIMEOUT_S=3.0`（断流死人开关）、`LWAA_ENABLE_ARBITRAGE_HEDGE=True` 且仅在 `pair_cost ≤ 1.00` 时补腿、`ALLOW_TAKER_UNWIND=False`（禁止恐慌斩仓）。

形态盈亏归因记账：结算时按入场时刻自动归类行情形态——箱体震荡 `range_bound`、常态微震 `normal_oscillation`、单边趋势 `trending_up`/`trending_down`、偏斜漂移 `skewed_drift`、宽价差 `wide_spread`、毒流防守 `toxic`、尾盘冻结 `tail_freeze`、过渡 `transitional`。看板实时展示各形态下的实际胜率与净盈亏，纯事后展示，不干预交易流程；没有入场标签的历史窗口单独归入 `unlabeled`/`legacy` 桶，不折叠进任何真实形态。
